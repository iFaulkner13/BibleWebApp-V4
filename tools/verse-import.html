Verse Import Tool

Turns plain verse text into correctly escaped JavaScript for the translations object in index.html. Escaping is the point: one bare apostrophe in a pasted verse took the whole app down.

How to use it

Paste one verse per line on the left, reference and text separated by a tab, a pipe, or an equals sign:

1:1      Ang pagkasaysay ng lahi ni Jesucristo...
1:2      Kay naging anak ni Abraham si Isaac...

A full reference works too, and the book name is ignored — only the chapter:verse is used:

Luke 1:1 | Yamang marami ang nagpilit mag-ayos...

Pick the language and book, press Convert, then paste the right-hand output into the matching book inside translations in index.html.

What it protects against:

  • apostrophes and quotes inside the verse (the bug that broke the app)
  • backslashes, tabs, and stray line breaks
  • duplicate references in your paste
  • references that are not chapter:verse

The output is validated by actually parsing it before it is shown, so what you copy is known to be loadable.
